研究背景与意义

H5 类幸存者玩法爆发，需在浏览器单线程约束下实现可维护、可验证的工程原型

1H5/WebGL 普及，浏览器单主线程限制帧预算
2Survivor-like + Roguelite：自动攻击、怪潮、局内构筑
3深继承 OOP 同屏数百实体时耦合高、难维护
4目标：轻量 ECS + JSON 配表 + 池化/Worker 可落地
5交付：菜单→跑图→战斗→装配→死亡重启闭环

国内外研究现状

引擎分层、ECS 组合、怪物 AI 与 Worker 卸载四条文献脉络支撑本课题技术选型

1Gregory 引擎分层；Ullmann 子系统耦合与架构退化
2ECS 组合优于继承；课设采用轻量 Map-ECS
3怪物：追玩家 + Boids 式排斥；非完整社会力模型
4Worker 卸追逐/分离重算；碰撞与渲染留主线程
5结论：模块化 + 重算分离 + 可验证

主要创新点与工程特色

1轻量 ECS：EcsWorld 驱动 tick；ViewComponent 只绑 Laya 节点

3UI 协同：UIStackManager + Tab/paused 统一切断战斗
