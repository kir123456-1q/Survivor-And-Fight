研究背景与意义

1H5 链接即玩跨端，但浏览器单主线程限制帧预算
2Survivor-like：自动攻击、怪潮、局内构筑 + Roguelite
3痛点：同屏实体多，深继承 OOP 耦合高难维护
4目标：验证轻量 ECS + 配表 + 池化/Worker 可落地
5交付：菜单→跑图→战斗→装配→死亡重启闭环

国内外研究现状

1引擎分层：Gregory 思想；Ullmann 子系统耦合与架构退化
2ECS：组合优于继承；课设采用轻量 Map-ECS
3怪物运动：追玩家 + Boids 式排斥；非完整社会力
4H5 性能：Worker 卸追逐/分离重算；碰撞留主线程
5结论：文献支持模块化 + 重算分离 + 可验证

性能优化方案

对象池 + Worker 单帧管线

BulletPool / MonsterPool 按预制体分桶
Worker 卸载追逐/分离/摆动重算
失败回退 computeSync；碰撞留主线程
paused 时战斗 System 统一早退
TextureAtlasService 动态图集合批
