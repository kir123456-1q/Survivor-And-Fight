\upcabstracttitle
\songti\zihao{-4}
\setlength{\parindent}{2em}
HTML5 与 WebGL 成熟后，浏览器已能运行中等规模的实时动作游戏。类吸血鬼幸存者玩法依赖单局随机、构筑与同屏实体压力，适合用 ECS 组织逻辑并控制帧率。本文题目为《\thesistitle》，以 \textbf{Survivor And Fight} 工程为例，基于 LayaAir 3.x 与 TypeScript 完成 2D 俯视角原型：轻量 ECS 拆分坐标、属性、技能与输入；JSON 配表配置伤害与子弹；对象池减少预制体反复创建，实体过多时把追逐等数值计算放到 Web Worker。

元流程含主菜单、选关、三幕 DAG 跑图及 Tab 技能装配。论文按需求、设计、实现、测试组织。千怪压力场景下，对象池把 P95 帧时间从约 76.5\,ms 压到 48.6\,ms；动态图集使该场景平均 FPS 提高约 13.4\%。Worker 在预热后的同窗消融尚未完成，列为后续实验。

\upckeywords{实体组件系统；类吸血鬼幸存者；LayaAir；数据驱动；Web Worker；对象池}

\upcabstracten
\zihao{-4}
\setlength{\parindent}{2em}
HTML5 and WebGL now support moderately complex real-time games in the browser. This thesis covers the development and optimization of a vampire-survivor-like game built on an ECS architecture (off-campus project). The Survivor And Fight prototype on LayaAir 3.x and TypeScript uses a lightweight ECS; bullets and modifiers are loaded from JSON tables; object pooling cuts allocation churn, and a Web Worker recomputes chase logic when entity counts are high. Menus, level pickers, and a three-act DAG map form the meta loop. Under a 1000-monster stress case, pooling lowered P95 frame time from about 76.5\,ms to 48.6\,ms; dynamic atlasing raised average FPS on the heaviest wave by roughly 13.4\%. A warmed-up, same-session Worker ablation is planned as follow-up work.

\upckeywordsen{ECS, vampire-survivor-like, LayaAir, data-driven, Web Worker, object pooling}
