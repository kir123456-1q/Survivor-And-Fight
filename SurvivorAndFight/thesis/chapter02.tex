\section{LayaAir 游戏引擎与 TypeScript}

LayaAir 是面向 HTML5 的跨平台游戏引擎，支持 2D、3D 与 UI。本项目使用 LayaAir 3.x，脚本以 TypeScript 编写，通过 \texttt{Laya.Script} 挂载至 \texttt{Area2D} 子节点，避免不必要的 3D 渲染管线开销。主循环由 \texttt{Laya.timer.frameLoop} 驱动，\texttt{EcsWorld.update(deltaTime)} 在每帧调用，实现逻辑与渲染解耦。商业引擎手册与架构文献均强调主循环、资源管理与场景更新的一致性\cite{gregory2018game,unitymanual2016}。

TypeScript 提供静态类型与模块化，静态常量集中于 \texttt{src/defines/} 并由 \texttt{index.ts} 统一导出，符合可维护性设计原则\cite{briand2001maintainability}。

\section{实体组件系统}

ECS 包含 Entity（标识）、Component（数据）、System（逻辑）。本项目 \texttt{EntityId} 为数值类型，\texttt{ComponentStore} 按类型存储，\texttt{EcsWorld} 提供统一 \texttt{update} 入口。系统按 \texttt{input/logic/physics/render} 分组排序。玩法层包括 \texttt{PlayerTag}/\texttt{MonsterTag}、\texttt{MovementSystem}、\texttt{AttributeSystem}（含可溯源 modifier）、\texttt{SkillSystem}、\texttt{ControlSystem} 及 \texttt{FilterRegistry} 命名筛选器。该划分与 Gregory 所述“引擎子系统 + 游戏逻辑层”分层思想一致\cite{gregory2018game}，但实现规模适配教学项目。

\section{数据驱动与配表}

策划参数外置为 JSON 表，由 \texttt{tables.registry.json} 注册，\texttt{ConfigBootstrap.ensureGameConfigLoaded()} 加载。包含 \texttt{Character}、\texttt{Bullet}、\texttt{Skill}、\texttt{SkillEffect} 等表。效果类型包括 \texttt{bullet}、\texttt{modifier\_split}、\texttt{modifier\_chain}、\texttt{modifier\_pierce}、\texttt{direct\_damage}，由 \texttt{EffectExecutor} 分发。\texttt{FormulaParser} 解析伤害公式；\texttt{Targeting} 支持自动索敌与指向输入。

\section{Roguelite 与跑图}

每局生成三个大关，每关为多层 DAG，节点含休息、战斗、Boss、宝藏等类型，\texttt{RunMapGenerator} 连接行际边并校验 Boss 可达。\texttt{SeededRng} 支持同种子复现。Helbing 等关于恐慌人群的研究提示：密集交互场景需关注分离与碰撞稳定性\cite{helbing2000panic}，与本项目怪物拥挤时的分离力设计相关。

\section{Web 性能与 UI 架构}

对象池（\texttt{BulletPool}、\texttt{MonsterPool}）减少实例化；\texttt{CombatDataBridge} 在实体数达标时将战斗快照提交 Web Worker；\texttt{BulletHitTest} 使用距离平方比较。\texttt{GameSession.paused} 在技能面板打开时暂停战斗逻辑。

UI 采用 MVC：\texttt{UiControllerBase} 定义生命周期，\texttt{UIStackManager} 管理全屏路由。Heijstek 等对比了架构描述的图文表示对理解效率的影响\cite{heijstek2011empirical}，本项目以代码模块划分配合 UI 栈，降低界面跳转歧义。
