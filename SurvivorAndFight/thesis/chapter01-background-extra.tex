
\section{相关游戏与竞品简要分析}

\textbf{吸血鬼幸存者}：极简操作加自动攻击和怪海，证明品类成立\cite{gregory2018game}。本项目借其节奏和升级感，但用 ECS 和 JSON 表把逻辑摊开，方便写进论文。

\textbf{杀戮尖塔}：节点地图加路线风险\cite{gregory2018game}。本文跑图也用 DAG，战斗却是实时俯视，瓶颈在帧率和碰撞。

\textbf{Noita}：模块拼法术带来深度\cite{gregory2018game}。本文 effect 链只吸收“组合”思路，不做像素物理。

\textbf{其他 H5 生存作}：不少仍用预制体加 OOP。本文用 ECS、配表和 Worker，强调可维护和可测，不拼内容量。
