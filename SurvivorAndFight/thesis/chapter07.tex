\chapter{系统测试与验证}
\label{chap:test}

本章对 Survivor And Fight 开展单元验证、功能回归与性能实验，验证第~\ref{chap:requirement}~章需求与第~\ref{chap:architecture}~章设计是否落地。测试策略遵循 Petty 等对仿真与交互系统 V\&V 的要求\cite{petty2010vv,oberkampf2010vv}：核心契约用脚本验证，玩法闭环用手工用例，性能用可复现关卡与日志统计。

\section{测试策略}

\textbf{单元验证}：ECS 核心、公式解析、属性修饰器——变更相关模块后须重跑对应 \texttt{*.verify.ts}。\\
\textbf{集成/系统测试}：跑图可达性、Tab 装配同步、Worker 轨迹一致性——手工或脚本断言。\\
\textbf{性能测试}：Level3 五波脚本 + \texttt{TestLevelFpsTracker}，对比表~\ref{tab:test-five-waves}、\ref{tab:perf}。\\
\textbf{回归清单}：修改 \texttt{FormulaParser}、\texttt{ComponentStore}、\texttt{AttributeSystem}、配表、\texttt{CombatDataBridge} 后，按附录需求—测试矩阵或表~\ref{tab:req-test-map} 回归主路径。

\section{单元验证}

\subsection{ECS 核心}

\texttt{ecsCorePhase1.verify.ts} 覆盖：实体 ID 唯一；组件增删与 \texttt{getComponent}；销毁后不可访问；多 System 按分组与 priority 顺序执行\cite{petty2010vv}。

\subsection{公式解析器}

\texttt{formulaParser.verify.ts} 覆盖：四则运算、括号、属性别名；非法字符与边界公式（以实现为准的安全返回/抛错）。配表伤害依赖解析器，任何变更须 rerun。

\subsection{属性修饰器}

\texttt{attributeModifier.verify.ts} 覆盖：多 modifier 叠加；按 \texttt{sourceId} 批量移除；\texttt{getModifierContributions} 可追溯。升级奖励与 Buff 均依赖该机制\cite{briand2001maintainability}。

\subsection{集成测试补充}

\textbf{跑图可达性}：对 \texttt{RunMapGenerator.generate} 多次随机种子断言 \texttt{validateActReachBoss}；失败应走 \texttt{generateFallback}。\\
\textbf{装配同步}：互换装备栏技能后，下一冷却周期伤害/图标与装配一致，否则 \texttt{SkillLoadoutSyncSystem} 存在缺陷。\\
\textbf{Worker 一致性}：Worker 开、关各跑一段，怪物轨迹可差一帧，但算法不能两套\cite{mckenzie2008crowd}。

\paragraph{结果解读}
\begin{enumerate}
  \item \textbf{规模曲线（第 1--3 波）。} 怪物 10$\rightarrow$100$\rightarrow$1000 时 FPS 由 58.62 降至 15.14，符合实体与弹幕压力上升规律。
  \item \textbf{平均 FPS：池化对均值影响有限。} 第 4、5 波均值接近（26.16 对 25.98），预热后瓶颈主要在子弹碰撞与绘制。
  \item \textbf{P95。} 开池后 P95 从 76.50\,ms 到 48.60\,ms（约降 36.5\%），和第~\ref{chap:performance}~章对 GC/实例化的判断一致。
  \item \textbf{第 3 波低于第 4 波基线。} 第 3 波含资源预热与首次千怪开销；消融结论以第 4--5 波为准。
  \item \textbf{Web Worker。} 本次未设「池+Worker、已预热」同窗段；Worker 定量收益列为后续工作。
\end{enumerate}

\section{测试结论}

\textbf{功能}：Must 用 T-F-01--10 和 \texttt{verify.ts} 覆盖；Should 的跑图、装配、升级、池/Worker 也测过；Could 的法杖三槽 UI 和部分 Effect 特效没做完，和第~\ref{chap:conclusion}~章一致。\\
\textbf{性能}：图集让千怪波 FPS 高约 13.4\%；五波整场均值约 34.48；同窗消融里池把 P95 拉低约 36.5\%。\\
\textbf{遗留}：配置未同步至 \texttt{bin/} 时图标可能空白（已用脚本与 \texttt{isGameConfigReady} 缓解）；Worker 预热后同窗消融待补。\\
\textbf{已知缺陷}：部分 Effect 仅逻辑生效、无独立 VFX，已在答辩范围中如实标注。

\section{本章小结}

本章给出测试策略、单元验证、功能用例、环境与五波性能数据及解读；对象池价值已由第 4--5 波实测支持。图~\ref{fig:ui-start}--\ref{fig:ui-restart} 为系统运行截图；Worker 同窗消融可作为后续实验补充。
