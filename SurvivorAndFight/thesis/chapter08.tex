\chapter{总结与展望}
\label{chap:conclusion}

\section{工作总结}

本文完成了 \textbf{Survivor And Fight} 在 LayaAir 3.x 与 TypeScript 上的 Roguelite 生存战斗游戏之分析、设计与实现。主要工作包括：轻量 ECS 玩法内核；配表驱动技能与子弹组合效果；对象池与 Web Worker 性能优化；元游戏、DAG 跑图与 MVC 界面；测试验证及社会影响讨论。

研究过程中参考了游戏引擎架构理解方法 SyDRA\cite{ullmann2025sydra}、经典引擎架构论述\cite{gregory2018game}，以及 Unity 物理人群疏散建模实践\cite{cantrell2018unity}，将模块化、物理仿真与验证思想迁移到 H5 教学原型中。系统可演示完整游戏循环，达到毕业设计预期。

\section{不足与展望}

\begin{enumerate}[label=\arabic*.]
  \item 法杖三槽完整 UI 与链式求值界面待完善；
  \item ECS 可迁移至 archetype 存储以提升同屏规模\cite{ullmann2023coupling}；
  \item 碰撞可引入空间哈希等 broad phase；
  \item 补充端到端自动化测试\cite{petty2010vv}；
  \item 局外存档与元进度；
  \item 美术特效与音效完善。
\end{enumerate}

\section{社会、健康与文化影响}

本游戏为虚构战斗题材，应标注适龄提示并避免过度暴力表现。长时间游玩需注意视觉疲劳；Tab 暂停提供局内休息点。教学原型不采集用户敏感信息。
