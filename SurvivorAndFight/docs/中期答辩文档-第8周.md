## 第4.5页 极简版 ECS 一帧执行图（答辩快讲版）

```mermaid
flowchart LR
  A[LayaAir frameLoop] --> B[EcsWorld update]
  B --> C[SystemScheduler]
  C --> D[按组件查询实体]
  D --> E[系统计算与写回组件]
  E --> F[ViewSync/HUD同步]
  F --> G[渲染结果]
```

快讲要点（30秒）：
- 每帧由引擎驱动一次 `EcsWorld update`。  
- 调度器按组和优先级执行系统。  
- 系统只通过“组件查询”拿数据并写回组件，不直接耦合实体实现。  
- 最后由渲染/同步系统把 ECS 状态映射到画面。
