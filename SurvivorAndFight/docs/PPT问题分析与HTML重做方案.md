# 答辩 PPT 问题分析与 HTML 重做方案

> **现状文件**：`基于ECS架构的类吸血鬼幸存者游戏开发及优化 (1).pptx` → `fix-gamma-defense-ppt.cjs` → `-已排版.pptx`  
> **HTML 重做**：`ppt-html/index.html`（浏览器预览）→ `scripts/export-html-slides-to-pptx.cjs`（导出 PPTX）

---

## 一、当前 PPT 效果差的原因

### 1. 插图链路先天不足

| 环节 | 问题 |
|------|------|
| **Mermaid CLI 导出** | 默认浅紫底 + 黑字，透明底 PNG 贴进深蓝模板后对比度差、像「贴了一张便签」 |
| **字号与密度** | flowchart / classDiagram 节点多，缩进 89%×45% 主图区后文字 ≤10pt，答辩后排看不清 |
| **序列图** | `sequenceDiagram` 竖向过长，横向主图区被压扁，参与者名截断 |
| **xychart-beta** | 柱图样式简陋，与学校模板橙蓝配色无关，无数据标签动画 |

### 2. 版式与内容错位

- Gamma 生成的 22 页与大纲 19 页**页序不一致**（如「创新点」落在第 20 页而非 16 页）。
- `fix-gamma-defense-ppt.cjs` 只处理了部分页（7–12、14–15、17–18、20–22），**章节过渡页、封面、目录未统一**。
- 版式 A 页堆叠「标题 + 引导 2 条 + 图 + 图注 + 底部 5 要点」，**垂直空间不足**，底部要点与图注打架。

### 3. 视觉层次缺失

- 五层架构、技能链等**核心图**与正文同等权重，缺少「主路径高亮 + 次要节点弱化」。
- 无入场动画规划：答辩时无法「先出架构再出数据流」，只能整页静态展示。
- 模板装饰（五环、卡片）与 Mermaid 图**风格割裂**——一套是商务模板，一套是工程草图。

### 4. 数据页表达弱

- 第 13–14 页性能数据是答辩重点，但柱图无 P95/FPS 数值标注，评委需对照底部小字。
- 对象池消融「均值 FPS 相近、P95 降 36.5%」这一**核心结论**在图上不直观。

## 二、HTML 重做策略（不用 Mermaid）

### 设计原则

1. **图表用 SVG + CSS 手绘**：圆角卡片、渐变箭头、分层色块，配色锁定模板深蓝 `#0d2b5e` + 橙 `#e87722`。
2. **动画服务讲解**：`stroke-dashoffset` 画箭头、`fade-up` 错峰入场；导出 PPT 时截「动画完成帧」。
3. **一图一观点**：主图区只保留 5–8 个节点；细节放底部要点，不放图里。
4. **先 HTML 定稿 → 再 PPT 还原**：浏览器全屏排练满意后，Playwright 逐页截图写入 PPTX。

### 文件结构

```
ppt-html/
  index.html          # 19 页幻灯片 DOM
  css/theme.css       # 模板色、版式 A/B、动画
  js/diagrams.js      # 各页 SVG 图表工厂（纯 HTML/CSS/SVG）
  js/app.js           # 键盘翻页、?export=1 导出模式
scripts/
  export-html-slides-to-pptx.cjs   # 截图 → pptxgenjs 组装
```

### 页型对照（与 `答辩PPT大纲.md` 一致）

| 页码 | 版式 | HTML 图表类型 |
|------|------|----------------|
| 1 | 封面 | 渐变网格 + 标题动效 |
| 2 | 目录 | 六卡片 stagger |
| 3–4, 12, 16–18 | 五环要点 B | 左要点 + 右迷你对比/脉络 SVG |
| 5–11, 13–15 | 单图 A | 全宽 SVG 主图 + 底部要点 |
| 19 | 致谢 | 居中排版 |

## 三、使用方式

### 1. 浏览器预览与排练

```bash
# 在项目根目录启动静态服务（任选其一）
npx --yes serve ppt-html -p 5173
# 或直接用 VS Code Live Server 打开 ppt-html/index.html
```

- `→` / `←` 或 `Space` 翻页  
- 全屏 `F11` 排练讲解节奏

### 2. 导出为 PPTX

```bash
cd SurvivorAndFight
node scripts/export-html-slides-to-pptx.cjs
# 输出：ppt-output/毕业答辩PPT-HTML导出.pptx
```

导出为**整页截图型**幻灯片（视觉与 HTML 一致）。若需可编辑文字，可在 PPT 中「置于顶层」补文本框，或以本 HTML 为视觉稿手工套学校模板。

### 3. 与旧流程的关系

| 旧流程 | 新流程 |
|--------|--------|
| Mermaid `.mmd` → mermaid-cli PNG | **废弃**，不再使用 |
| `fix-gamma-defense-ppt.cjs` 插图 | 改为 HTML 截图导出 |
| Gamma AI 直接生成 PPT | 仅作文案参考，**版式以 HTML 为准** |
