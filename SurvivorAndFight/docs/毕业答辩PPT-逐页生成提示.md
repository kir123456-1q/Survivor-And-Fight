### 第 11 页｜公式树解析与求值（FormulaParser）

| 项 | 内容 |
|----|------|
| **标题** | 配表公式树：解析与安全求值 |
| **版面建议** | 左 40% 四步流程竖条 + 右 60% **图 5-5**；页脚放 AST 小图与算例 |
| **讲解** | 1.5～2 分钟：从配表字段讲到为何不用 eval，可口算 `(atk+5)*2` 示例 |

#### 正文要点（PPT  bullet，≤5 条）

| # | 要点 |
|---|------|
| 1 | **触发位置**：`SkillEffect` 表 `effect=direct_damage`，字段 `paramsFormula`（如 `"atk*1.5+10"`） |
| 2 | **数据流**：`EffectExecutor` → 遍历施法者 `Attribute.base` 键 → `AttributeSystem.getFinalValue` 建 **context** → `evaluate(formula, context)` 扣目标 hp |
| 3 | **四层实现**（对应图 5-5 主链）：① `ALLOWED_PATTERN` 白名单校验 → ② `tokenize` 词法 → ③ 递归下降 `parseFormula` 建 **AST** → ④ `evaluateFormula` 后序求值 |
| 4 | **AST 四类节点**：`number` / `ident` / `unary(-)` / `binary(+-*/)`；**禁止 `eval` / `new Function`** |
| 5 | **验证**：`formulaParser.verify.ts` 锁语义；改 Parser 须 rerun；功能用例 **T-F-04** 对照局内直伤 |

#### 四层流程详表（可做成左侧竖向流程图）

| 层级 | 函数/产物 | 说明 |
|------|-----------|------|
| ① 入口约束 | `ALLOWED_PATTERN` | 仅允许数字、标识符、括号、四则运算符；非法字符在 tokenize 前抛错 |
| ② 词法 | `tokenize` | 输出 `number` / `ident` / `op` / `lparen` / `rparen`；`ident` 须与 `Attribute.base` 字段名一致（如 `atk`、`hp`） |
| ③ 语法 | `parseFormula` | 递归下降：`parseAddSub` → `parseMulDiv` → `parseUnary` → `parsePrimary`；体现 **乘除优先于加减** |
| ④ 求值 | `evaluateFormula` | `ident` 必须在 context 中存在，否则 `unknown identifier`；**除数为 0 返回 0**（避免 NaN） |

#### 与属性修饰器的关系（答辩常问，可放备注区）

```
modifier（升级/Buff）→ AttributeSystem 写 modifier 列表
                              ↓
direct_damage 结算时 getFinalValue(atk) 等进入 context
                              ↓
公式树 ident「atk」读到的是叠加后的最终攻击力
```

- 公式里标识符名必须与 `base` 字段一致，否则求值失败。  
- 链路：**modifier → context → 公式树 → 扣 hp**（对应论文 7.2.3、图 5-1 的 `direct_damage` 分支）。

#### AST 示例（建议占页右下角 1/4）

**配表**：`paramsFormula = "(atk+5)*2"`  
**假设 context**：`{ atk: 20 }` → 结果 `(20+5)*2 = 50`

```
        [*]              ← 根：乘号（乘除优先）
       /   \
    [+]     [2]
   /   \
[atk]  [5]
```

| 节点 | 类型 | 求值 |
|------|------|------|
| 根 | `binary *` | 25 × 2 = **50** |
| 左子树 | `binary +` | 20 + 5 = 25 |
| 右子树 | `number` | 2 |

#### 安全与设计取舍（一句话放页边注）

| 对比 | 本文做法 |
|------|----------|
| `eval("atk*1.5")` | ❌ 任意代码执行风险 |
| 字符串替换后 `new Function` | ❌ 仍可能注入 |
| **白名单 + AST + `evaluateFormula`** | ✅ 可单元测试、可复现、改表不改代码 |
