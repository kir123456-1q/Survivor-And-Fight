## 1.1 研究背景

### 【位置-01】§1.1 第1段 | Word：1.1 节首段 | LaTeX：`chapter01.tex` 第6行

**原文：**

随着移动互联网与 Web 技术的普及，H5 游戏在独立作品开发与教学实践中应用日益广泛。相较原生安装包，H5 游戏具有链接即玩、跨端发布、逻辑与资源共用 Web 技术栈等优势，有利于降低分发与迭代成本。然而，浏览器端 JavaScript 运行时通常仅有一条主线程，垃圾回收（GC）与渲染绘制共享帧时间预算；在战斗类场景中，若单帧内集中处理大量实体移动、碰撞检测与界面刷新，玩家将直接感知到帧率下降，影响可玩性。

**改写：**

移动互联网与 Web 技术普及后，H5 游戏在独立开发和教学实验里用得较多。相对安装包，H5 支持链接打开、跨端发布，逻辑与资源也走 Web 技术栈，分发和改版本更方便。浏览器里 JavaScript 多为单线程，GC 与绘制共用每帧时间。战斗类若在同一帧里集中做位移、碰撞和 UI 刷新，帧率会掉，玩家能直接感觉到。

## 附：常见 AI 痕迹与本次处理（对照检测习惯）

|----------|--------------|----------|
| 排比句 | 「有助于…展示了…代表了…」连用 | 各句换主语，避免四字排比 |
| 空泛副词 | 日益、较为、进一步、相对 | 删减或改具体表述 |
| 长复合句 | 一分号串多件事 | 拆成 2–3 个短句 |
| 套话 | 「基于上述背景」「综合…可以看到」 | 改直接陈述 |
| 过度正式 | 「加以支撑」「工程化参考」 | 保留术语，口语化动词 |
