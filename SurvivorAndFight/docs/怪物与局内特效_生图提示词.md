# 怪物与局内特效 — 图集尺寸、切图排布与完整生图提示词

说明：下列「完整提示词」为**单条**可直接投喂文生图模型的正文；图内按坐标排布，导出后按像素矩形切图。**整张画布与各格未占用的区域须为透明背景（Alpha=0）**，仅角色与特效本体带不透明或半透明像素；无文字无水印。若生成工具难以一次输出整图透明底，可先出图再在美术软件中统一抠除底色并导出 **PNG 带 alpha**。格与格之间可留 **1～2px** 极细对齐参考线（低不透明度）或完全不留线、仅靠坐标裁切。
