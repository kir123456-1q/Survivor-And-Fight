# 美术素材与界面制作清单（元流程 · 跑图 · 法术编程）

对应变更：`openspec/changes/add-meta-flow-run-map-spellcraft/`。

本文档列出须制作的 **UI 界面**、**图标与插画**、**特效与地图元件**，用于策划与美术拆分工作量；分辨率与命名在项目确立 UI 稿后冻结。

---

## 一、界面（按流程）

### 1. 开始界面（Title）
- **标题图（Logo）**：独立图层导出（透明底 PNG），不含按钮与全屏背景
- **按钮图**：主按钮「开始游戏」与次级入口「设置」「退出」等，透明底散图或横向图集
- **背景图**：全屏氛围底图（1920×1080），不含 Logo、按钮与 UI 框
- 须提供安全区与按钮热区标注（可与一张仅供对齐用的合成示意图一并交付）

### 2. 选局界面（PreRun）
- 显示本局规则摘要：种子展示或复制入口、难度或加成条目占位
- 主按钮「确认开局」、返回标题
- 用于承载开局参数；视觉风格须与标题、跑图一致

### 3. 跑图界面（RunMap）
- **地图底板**：三大关分区背景或 Tab；当前大关高亮
- **节点元件**：篝火、商店、普通战、精英战、问号事件；每个类型须含「未访问 / 已访问 / 当前选中」至少三种状态
- **连线**：层与层之间的路径；须区分「可走 / 不可走 / 已走过」
- **玩家标记**：当前所在节点指针或头像图标
- **顶端信息条**：资源摘要占位（金币、生命、药剂等按后续策划列项）

### 4. 局内法术装配（与 HUD 结合）
- **三支法杖槽**：横向或径向排列；须区分「空槽 / 已装备 / 当前选中」
- **单支法杖详情面板**：槽位列表（子弹槽、修饰槽等）；拖拽或点击装配交互占位
- **法术片段库**：背包或弹窗列表；片段图标、名称、稀有度边框
- **施放反馈**：当前选中法杖高亮、冷却或能量条占位（若策划采用 CD / 能量）

### 5. 通用组件
- 模态对话框（确认 / 取消）、Toast、加载遮罩
- 暂停菜单（与 `PauseOverlay` 对应）：继续、返回跑图或标题的规则在产品层冻结后补全

## 二、图标与小图（2D）

| 类别 | 说明 |
|------|------|
| 跑图节点 | 篝火、商店、骷髅（小怪）、皇冠或盾（精英）、问号 |
| 法杖 | 至少三种外观区分三支槽位皮肤或通用法杖图标 + 编号 |
| 法术片段 | 子弹类、修饰类、功能类各一套底色或符号体系 |
| 元界面 | 设置、返回、确认、锁定、警告 |

规格建议：同一界面内图标统一边距与圆角底板；导出 PNG/WebP + 可选 SVG 源文件。
